# Alpha-RL v1.0.0 Release Notes

Alpha-RL 1.0.0 marks the initial production release of the Deep Reinforcement Learning engine for quantitative finance.

### Highlights:
- Continuous PPO with Generalized Advantage Estimation (GAE) and orthogonal initialization.
- PatchTST-inspired Temporal Patch Transformer with Cross-Asset Attention.
- Almgren-Chriss optimal order execution environment and L2 order book depth queues.
- Institutional risk manager with Max Drawdown kill switch and dynamic volatility targeting.
- Purged & Embargoed walk-forward K-Fold cross-validation splits.
- Real-time FastAPI WebSocket gateway and dark-mode React 19 Quant Terminal.
